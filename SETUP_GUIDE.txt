================================================================
        KITA KONBINI MINIMART - PROJECT SETUP GUIDE
================================================================

Tech Stack:
  - Framework  : Laravel (PHP)
  - Frontend   : Blade Templates + Vanilla CSS/JS
  - Database   : MySQL (via Laragon)
  - Local Server: Laragon (port 8001)
  - Storage    : Laravel Storage (local disk)


================================================================
1. REQUIREMENTS
================================================================

Make sure you have these installed:
  - Laragon (includes PHP 8.x, MySQL, Apache)
  - Composer
  - Node.js & npm
  - Git


================================================================
2. SETUP AFTER CLONING
================================================================

Step 1 - Install dependencies
------------------------------
  composer install
  npm install && npm run dev


Step 2 - Setup environment file
---------------------------------
  1. Copy .env.example to .env
       copy .env.example .env

  2. Generate app key
       php artisan key:generate

  3. Edit .env - update database settings:
       DB_DATABASE=kita_konbini
       DB_USERNAME=root
       DB_PASSWORD=


Step 3 - Setup database
--------------------------
  1. Create database named "kita_konbini" in phpMyAdmin or HeidiSQL
  2. Run migrations and seed default data:
       php artisan migrate --seed


Step 4 - Storage link
-----------------------
  php artisan storage:link

  (This links the storage folder so product images load properly)

================================================================
6. COMMON ISSUES & FIXES
================================================================

Images not showing:
  --> Run: php artisan storage:link
  --> Check image filenames match exactly (case-sensitive)

500 Server Error:
  --> Run: php artisan config:clear
  --> Run: php artisan cache:clear
  --> Check .env file exists and APP_KEY is filled

Database error / table not found:
  --> Run: php artisan migrate
  --> If still error: php artisan migrate:fresh --seed
      WARNING: migrate:fresh will DELETE all existing data!

Class not found after adding new Model:
  --> Run: composer dump-autoload


================================================================
7. IMPORTANT NOTES
================================================================

  [!] NEVER run migrate:fresh --seed on a shared/production
      database - it will delete all data.

  [!] The .env file is NOT in the repo. Each teammate must
      create their own from .env.example.

  [!] Product images must be copied manually to
      storage/app/public/products/ after cloning.

  [*] After any new migration file is added by a teammate,
      run: php artisan migrate (NOT migrate:fresh)

  [*] Admin route is protected - only users with
      is_admin = true in the database can access /admin.
